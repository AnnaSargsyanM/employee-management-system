# Employee Management System

A Java project developed as part of my Computer Science coursework at Webster University.

## About

This project models different types of employees using object-oriented programming.

The program uses an employee class hierarchy with four specialized roles:
- Consultant
- Marketing Specialist
- Clerk
- Sales Associate

## Class Structure

- `Employee` - base class containing common employee information
- `Staff` - extends Employee and represents salaried employees
- `Hourly` - extends Employee and represents hourly employees
- `Consultant` and `MarketingSpecialist` - extend Staff
- `Clerk` and `SalesAssociate` - extend Hourly
- `Runner` - creates employee objects and demonstrates their behaviors

## Concepts Used

- Java
- Object-Oriented Programming
- Inheritance
- Encapsulation
- Constructors
- Method Overriding
- Getters and Setters
